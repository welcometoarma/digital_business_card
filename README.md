
# Mondello Beach Vitamin Sea — Digital Business Card

A beautiful, mobile-first digital business card for the "Mondello Beach Vitamin Sea" Airbnb property in Mondello, Sicily. This single-page application combines stunning beach-themed design with practical functionality, allowing guests to easily view property details, save contact information, and share with friends.

## ✨ Features

### 🎨 Design & Theme
- **Sky, Sea & Beach Theme**: Gradient background transitioning from deep ocean blue to golden sandy shores
- **Animated Elements**: Pulsing sun, drifting clouds, and gentle wave animations
- **Glass-morphism Effect**: Frosted glass card design with backdrop blur for modern aesthetic
- **Fully Responsive**: Optimized for all screen sizes from desktop to mobile devices

### 📋 Property Showcase
- **Key Amenities**: 2 Beds, 1 Bath, Kitchen
- **Host Information**: "Superhost" badge with host name
- **Photo Slideshow**: 6 property images with auto-rotation (every 3.5 seconds)
- **Manual Controls**: Click dots to navigate, tap images for fullscreen view

### 🔗 Quick Actions
- **Book Now**: Direct link to Airbnb listing
- **Add Contact**: One-tap save to phone contacts (vCard format)
  - 📱 **Android**: Opens directly in Contacts app
  - 📱 **iOS**: Downloads .vcf file for easy import
  - 💻 **Desktop**: Downloads .vcf file
